6: Executive Summary
7: The conventional public service hearing protocol (typically held on designated days like Wednesday and Friday) suffers from severe physical queuing, cumbersome bureaucracy, lack of traceability, and human bottlenecks across hierarchical governance tiers (Woreda  Sub-City  City Administration).
8: This platform completely replaces manual intake and dispute resolution with an end-to-end, automated, role-governed digital architecture. It integrates multi-channel citizen input, automated Service Level Agreement (SLA) timers, rules-based hierarchical escalation, virtual appointment rooms, and cryptographic verification via digital signatures and QR codes.
9: Core Objectives
10: Zero In-Person Bureaucracy: Enable citizens to submit grievances, voice notes, and supporting documents remotely via a Telegram Bot or Mobile Web Portal.
11: Enforced Administrative Accountability: Apply strict, immutable SLA countdowns to cases. If an official fails to act within the mandated timeframe, the system automatically escalates the case to the next administrative echelon without human discretion.
12: Digitized Direct Hearings: Replace physical attendance days with scheduled virtual hearings integrated with video conferencing, digital signature sign-offs, and instant PDF resolution dispatches.
13: End-to-End Observability: Provide transparent public case tracking via ticket IDs/QR codes and an executive dashboard highlighting real-time administrative bottlenecks and response latencies.

543: user_id: str = payload.get("sub")
544: if user_id is None:
545: raise credentials_exception
546: except JWTError:
547: raise credentials_exception

550: if user is None:
551: raise credentials_exception

554: raise HTTPException(

556: detail="Inactive user account."
557: )

561: class RoleChecker:
562: """Reusable dependency to enforce role-based authorization across API endpoints."""
563: def __init__(self, allowed_roles: List[UserRole]):
564: self.allowed_roles = allowed_roles
566: def __call__(self, current_user: User = Depends(get_current_user)) -> User:
567: if current_user.role not in self.allowed_roles:
568: raise HTTPException(
569: status_code=status.HTTP_403_FORBIDDEN,
570: detail=f"Operation not permitted. Required role: {[r.value for r in self.allowed_roles]}",

651: Core Design Principles
652: Separation of Concerns: Business logic (SLA deadlines, escalations) is decoupled from transport mechanisms (FastAPI endpoints, Telegram webhooks).
653: Immutable Auditability: The cases table maintains current operational state, while case_audit_logs acts as an append-only ledger of every mutation, manual change, and automated escalation.
654: Optimistic Locking with Distributed Consensus: Concurrent state mutations and multi-worker SLA reviews use PostgreSQL row-level locks (SELECT ... FOR UPDATE SKIP LOCKED) and Redis distributed locks (Redlock) to eliminate duplicate escalations.
655: Idempotency: All webhook endpoints, background worker jobs, and escalation transitions accept idempotency keys (X-Idempotency-Key or hashed event IDs).

937: 6.3 Transactional Escalation Worker Task (src/workers/tasks_sla.py)
938: Python
939: from datetime import datetime, timezone, timedelta
940: from sqlalchemy import select
941: from sqlalchemy.orm import selectinload
942: from src.core.database import AsyncSessionLocal
943: from src.modules.cases.models import Case, CaseStatus
944: from src.modules.administration.models import AdministrativeStructure, AdminLevel
945: from src.modules.audit.models import CaseAuditLog
947: async def execute_sla_escalation_sweep():
948: """
949: Scans for expired tickets using row-level locking (SKIP LOCKED)
950: to allow concurrent worker scaling without duplicate escalations.
951: """
952: now = datetime.now(timezone.utc)
954: async with AsyncSessionLocal() as session:
955: async with session.begin():
956: # Acquire lock on breached cases only
957: stmt = (
958: select(Case)
959: .where(
960: Case.status.notin_([CaseStatus.RESOLVED, CaseStatus.REJECTED]),
961: Case.sla_deadline <= now,
962: )
963: .with_for_update(skip_locked=True)
964: .limit(100)
965: )
966: result = await session.execute(stmt)
967: breached_cases = result.scalars().all()
969: for case in breached_cases:
970: # Load current administrative node
971: struct_stmt = (
972: select(AdministrativeStructure)
973: .where(AdministrativeStructure.id == case.current_structure_id)
974: )
975: struct_res = await session.execute(struct_stmt)
976: current_struct = struct_res.scalar_one_or_none()
978: if not current_struct or not current_struct.parent_id:
979: continue  # Already at top municipal tier or unlinked
981: # Escalate Woreda -> Sub-City
982: if current_struct.level == AdminLevel.WOREDA:
983: case.current_structure_id = current_struct.parent_id
984: case.status = CaseStatus.ESCALATED_TO_SUBCITY
985: case.is_escalated = True
986: case.escalation_count += 1
987: case.sla_deadline = now + timedelta(hours=24)
989: audit = CaseAuditLog(
990: case_id=case.id,
991: performed_by=None,  # System Actor
992: action="AUTO_ESCALATED_SLA_BREACH",
993: old_value={"status": CaseStatus.SUBMITTED.value, "level": "WOREDA"},
994: new_value={"status": case.status.value, "level": "SUB_CITY"},
995: notes="Automated SLA breach transition from Woreda to Sub-City."
996: )
997: session.add(audit)
999: # Escalate Sub-City -> City Administration
1000: elif current_struct.level == AdminLevel.SUB_CITY:
1001: case.current_structure_id = current_struct.parent_id
1002: case.status = CaseStatus.ESCALATED_TO_CITY
1003: case.is_escalated = True
1004: case.escalation_count += 1
1005: case.sla_deadline = now + timedelta(hours=24)
1007: audit = CaseAuditLog(
1008: case_id=case.id,
1009: performed_by=None,
1010: action="AUTO_ESCALATED_TO_CITY",
1011: old_value={"status": CaseStatus.ESCALATED_TO_SUBCITY.value, "level": "SUB_CITY"},
1012: new_value={"status": case.status.value, "level": "CITY"},
1013: notes="Automated SLA breach transition from Sub-City to City Administration."
1014: )
1015: session.add(audit)
1017: # Changes persist when exiting session.begin() context manager
